# CareBridge — Project Memory

## Purpose
Build a dependable, India-wide multilingual telemedicine platform in controlled phases.

## Confirmed requirements
- JavaScript is the primary implementation language.
- English and Hindi initially; extensible for more Indian languages.
- Manual location selection and optional device location.
- Nearby-first doctor discovery; eligible online doctors elsewhere remain searchable.
- LiveKit video consultations.
- Doctor-specific consultation fees.
- Specific date/time appointment slots.
- Patient, doctor, and admin roles.
- Digital prescriptions and protected patient records.

## Working rules
- Finish and review documentation before application coding.
- Make small, scoped changes.
- Inspect only relevant files for each task.
- Preserve existing working behavior; avoid unrelated changes.
- Test each phase before moving forward.
- Never trust client-side authorization or payment state.
- Record major decisions in `DECISIONS.md` and active work in `TASKS.md`.

## Current phase
Documentation and requirements. Do not implement application features until PRD is approved and architecture decisions are settled.
